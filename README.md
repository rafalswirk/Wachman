===
Time tracker with pomodoro timer. It's still in development. I want to use it, to improve my work performance. Application will be splitted into two parts. First one - TimeTracker, will connect with TimeCamp service to track current work.

With recent changes application go threw big refactoring and moved from this:
![Screenshot1](/docs/images/wachman-main-screen.png)
Into this:
![Screenshot1](/docs/images/focusforge-main-screen.png)
Also application name was changed from Wachman to FocusForge.

Second part - pomodoro, is always on top timer that shows current task and count down till break.

![Screenshot1](/docs/images/pomodoro-timer.png)

With red color it looks cool with light and dark mode. Transparent backgroud makes it non-distracting. When mose pointer is over the timer then background is switched to acrylic one. It improves read-ablility of timer.

![Screenshot1](/docs/images/pomodoro-acrylic-background.png)

Plans for near future:
* Reading current tasks data from TimeCamp
* Setting new tasks directly from desktop app
* Charts for showing work progress for current day/month
* Reports generation
